# 露天矿边坡安全监测面板

采场边坡 + 排土场边坡的 GNSS 位移监测与雷达边坡监测一体化面板。

## 功能

- **3D 坡面示意图**：台阶式采场（下凹）与排土场（上凸）三维地形，16 个 GNSS 监测点 + 1 套雷达监测站（含扫描射线）按真实方位布点，自动旋转、可拖拽缩放
- **安全等级四色标识**：绿 安全 `<2 mm/d` ｜ 黄 预警 `2~5 mm/d` ｜ 橙 警示 `5~10 mm/d` ｜ 红 报警 `>10 mm/d`，页头实时统计、点位颜色与速率联动
- **逐小时数据**：每点 30 天 × 24 条（水平位移、垂直位移、位移速率），最近整点更新
- **点位详情**：点击 3D 测点或侧栏列表 → 近 30 天位移-时间曲线（累计位移 + 速率双图联动缩放），速率曲线按等级分段着色并标注 2/5/10 mm/d 报警阈值线，可导出 CSV
- **报警事件**：近 7 天等级跃升事件自动汇总
- **周报自动生成**：页面加载即生成最近 7 天报告（总体情况 / 采场 / 排土场 / 雷达 / 报警记录 / 结论建议），支持重新生成、下载 HTML、打印/PDF

## 运行

无需构建，ECharts 已本地化（`vendor/`），直接打开即可：

```bash
# 方式一：直接双击 index.html
# 方式二：本地服务
cd slope-monitor && python3 -m http.server 8000
# 浏览器访问 http://localhost:8000
```

## 目录

```
slope-monitor/
├── index.html          # 页面结构
├── css/style.css       # 深色工业风样式（含打印样式）
├── js/data.js          # 数据模型：地形 + 17 点 × 30 天逐小时模拟数据 + 统计
├── js/app.js           # 3D 场景 / 列表 / 弹窗曲线 / 周报逻辑
└── vendor/             # echarts 5.5 + echarts-gl 2.0本地化
```

## 说明

- 当前为**演示数据**（固定随机种子，刷新结果一致）。接入真实系统时，将 `js/data.js` 中的序列生成替换为接口数据即可，统计与报表逻辑无需改动
- 演示场景：GP-03（采场北坡）处于加速变形红色报警，雷达 RD-01 同步监测该区域；GD-02（排土场东坡）速率缓慢抬升越过橙色警示线
