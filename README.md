# 露天矿边坡安全监测面板

采场边坡 + 排土场边坡的 GNSS / 雷达联合监测可视化面板。纯前端实现，无需后端，数据由内置模拟器按「逐小时上报」生成。

## 运行方式

直接双击打开 `index.html` 即可（所有依赖已本地化，离线可用）。

或启动本地服务：

```bash
cd 本目录
python3 -m http.server 8080
# 浏览器访问 http://localhost:8080
```

## 功能

| 模块 | 说明 |
|------|------|
| 3D 坡面示意 | 台阶式采场 + 排土场地形，20 个监测点（GNSS 球形标 / 雷达菱形标）按真实位置布设，两台边坡雷达动态扫描 |
| 安全等级着色 | 绿 <2mm/d · 黄 2~5 · 橙 5~10 · 红 >10，警示/报警点带脉冲光环 |
| 逐小时上报 | 演示模式 3 秒 = 1 小时，实时刷新位移量、状态、日志与报警事件 |
| 测点曲线 | 点击 3D 测点或列表 📈：近 30 天「位移-时间」曲线（含 2/5/10 mm/d 阈值参考斜线）+「速率-时间」曲线（含三级报警阈值线） |
| 周报自动生成 | 启动即自动生成最近 4 期周报；含监测概况、位移成果表、重点测点分析、报警事件统计、自动结论与建议；支持打印与 HTML 下载 |
| 视角联动 | 列表点击 → 3D 飞行定位；全景 / 采场 / 排土场 一键切换 |

## 目录结构

```
index.html          页面布局
css/style.css       深色监控中心风格 + 报告打印样式
js/data.js          地形参数、测点布设、30天×24h 数据模拟、报警检测
js/scene3d.js       Three.js 3D 场景（地形/测点/雷达/拾取）
js/charts.js        ECharts 位移-时间 / 速率-时间 曲线弹窗
js/report.js        周报统计、自动生成、渲染、打印/下载
js/main.js          UI 渲染与实时上报循环
vendor/             three.js r128 / OrbitControls / echarts 5.5（本地化）
```

## 说明

- 数据为演示模拟：采场-P08 为加速蠕变危险点（红色报警），采场-P04 约 17 天前曾短时超限后回落，其余测点各有平稳/预警状态，便于展示全部分级与报告逻辑。
- 安全等级阈值、矿山名称、测点布设等均在 `js/data.js` 顶部 `CONFIG` / `STATUS` 中配置。
